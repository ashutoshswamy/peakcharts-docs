# peakcharts docs

Documentation site for [peakcharts](https://www.npmjs.com/package/peakcharts), accessible React charts with purposeful motion.

- Site: https://peakcharts.ashutoshswamy.in
- Package: https://www.npmjs.com/package/peakcharts
- Package repo: https://github.com/ashutoshswamy/peakcharts

The site is built with the package it documents. Every chart demo on these pages is a real `peakcharts` chart.
